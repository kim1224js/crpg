# Weapon sounds

- `sword_swing.wav`, `spear_swing.wav`: Swishes Sound Pack by artisticdude, CC0 — https://opengameart.org/content/swishes-sound-pack
- `bow_shot.wav`: Battle Sound Effects by artisticdude, available under CC0 — https://opengameart.org/content/battle-sound-effects
- `gun_shot.ogg`: Residue SFX by FacadeGaikan, CC0 — https://opengameart.org/content/residue-sfx
