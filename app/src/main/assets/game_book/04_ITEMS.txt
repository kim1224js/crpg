[기본 소모품]
횃불: 5개 묶음 1G. 사용한 층 동안 모든 무기 공격력 +1.
귀환석: 1개 2G. 생존 중 마을로 안전 귀환.
야영 세트: 1개 3G. 최대 HP까지 회복.
화염병: 1개 2G. 사거리 3, 3×3 화염 지대, 2턴간 턴당 5 피해,
         피격 대상은 3턴간 턴당 3 화상 피해.

[기본 무기]
조잡한 검: 공격 3, 1턴, 인접 8방향의 모든 적 공격.
조잡한 창: 공격 4, 2턴, 직선 사거리 3 전체 찌르기.
조잡한 활: 공격 3, 1턴, 사거리 4, 50% 확률 추가 사격.
조잡한 총: 공격 5, 2턴, 사거리 5, 처치 시 직선 관통.

[기본 방어구]
조잡한 갑옷·투구: 방어 성공 확률 30%, 성공 시 MISS와 피해 무효.
조잡한 신발: 이동 관련 확률 효과.

[장비 분류]
WEAPON, HELMET, ARMOR, BOOTS, AUXILIARY, ACCESSORY, RELIC.
보조장비와 악세서리는 전용 장착칸을 사용한다.
유물은 인벤토리에 소지하면 자동 발동하며 사망 시 상실한다.

[던전 인벤토리 조작]
아이템을 한 번 누르면 이름, 등급, 분류, 수량, 옵션과 장착 상태를 공통 팝업으로 표시한다.
소모품은 정보창의 사용 버튼으로 사용하고, 장비는 장착 버튼으로 교체한다.
이미 장착한 장비와 자동 발동 유물은 정보만 표시한다.

[DB]
상세 이름, 등급, 가격, 공격력, 턴 비용, 사거리, 효과 코드, 드랍률,
아이콘과 캐릭터 시트 경로는 item_definition을 기준으로 한다.
기본 상점 장비의 개별 던전 드랍률은 5%다. 소모품과 몬스터 전용 장비는 각 DB 확률을 별도로 따른다.
[감정 능력치 변동]
- 고급 이상 미확인 장비의 감정 성공 시 장비 개체별 결과를 DB에 영구 저장한다.
- 공격력이 있는 장비: 원본 공격력의 50~150% 범위에서 균등 무작위 결정한다. 최소 1.
- 확률형 고유 효과는 감정으로 변경하지 않고 장비 원본 확률을 그대로 사용한다.
- 감정된 공격력은 장비 정보창 및 실제 던전 전투 계산에 사용한다.
- 사거리, 턴 비용, 고유 효과의 종류는 변하지 않는다.
- 감정 성공 시 전체 기본 효과를 공통 스크롤 팝업으로 공개한다.
- 감정 변화는 원본 대비 공격력 ±수치와 수명 +수치만 별도로 표시한다.

[장비 원정 수명]
- 노말 3회, 고급 4회, 레어 5회, 에픽 6회, 유니크 7회, 전설 8회, 신화 9회.
- 고급 이상 장비는 감정 성공 시 기본 수명에 0~10회를 균등 무작위로 추가한다.
- 안전 귀환 또는 정상적인 탐험 종료 때, 출발 시 가져간 모든 장비의 사용 횟수가 1 증가한다.
- 사용 횟수가 수명에 도달하면 해당 장비는 귀환 정산 중 파괴된다.
- 던전에서 새로 획득한 장비는 해당 원정의 수명 차감 대상에서 제외한다.
- 장비 정보창에서 현재 사용 횟수와 총 수명을 확인할 수 있다.
