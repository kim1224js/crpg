[맵]
현재 1~25층. 논리 크기 24×12, 표시 영역 8×7.
배경은 1~5층 폐허, 6~10층 침수 카타콤, 11~15층 재의 용광로, 16~20층 악마의 심연, 21~25층 심연의 성소로 전환된다.
돌과 나무 장애물을 층마다 무작위 배치한다.
몬스터 종류와 수는 층별 DB 구성을 따르지만 실제 출현 좌표는 원정마다 무작위로 결정된다.
층마다 총 5~10마리가 무작위로 등장하며, DB의 층별 몬스터 구성을 반복 추첨한다.
보스층의 보스는 반드시 1마리 포함하고 추가 추첨에서는 중복되지 않는다.
첫 몬스터는 입구 인근에도 등장할 수 있으며, 나머지는 맵 전체에 분산된다.
몬스터 주변 최소 이동로는 장애물 생성에서 제외해 구조물에 완전히 갇히지 않게 한다.
맵을 드래그해 전체 영역을 확인한다.

[층 진행]
기본은 지하 1층에서 새 원정을 시작한다.
지하 10층을 완료하면 계정에 10층 시작 지점이 영구 해금되며 다음 세대에도 유지된다.
몬스터가 남아 있어도 계단을 이용할 수 있다.
전투 중에는 계단 근처까지 직접 이동해야 하며, 전투 종료 후에는 턴 소모 없이 자동 이동한다.
층 완료 팝업에서 마을가기 또는 내려가기를 선택한다.
25층에서는 내려가기 없이 마을가기만 표시한다.

[층 진입 안내]
층에 진입하면 3배속 기준으로 주요 구조물을 먼저 안내한다.
카메라는 회복 구조물, 미믹·보물 상자, 아래층 출구 순서로 이동한 뒤 플레이어에게 돌아온다.

[전투 종료 자동 이동]
층의 몬스터를 모두 처치한 뒤 계단, 샘물·천사상 또는 전리품을 누르면
가장 가까운 접근 가능 칸까지 최단 경로로 자동 이동한다.
자동 이동 중에는 추가 입력을 막고 카메라가 플레이어를 따라간다.
도착하면 계단 선택, 회복 시설 사용 또는 전리품 습득을 자동으로 이어서 실행한다.
전리품은 전투 중에도 멀리서 누르면 자동 이동하며 한 칸마다 몬스터 턴을 정상 진행한다.
몬스터가 경로를 막으면 우회 경로를 다시 계산하고, 길이 완전히 막히거나 플레이어가 사망하면 중단한다.
전리품은 상하좌우뿐 아니라 대각선으로 인접한 칸에서도 습득할 수 있다.

[회복 시설]
각 층에서 30% 확률로 시설 하나가 등장한다.
샘물 또는 천사상이 무작위로 선택되며 2×2, 총 4칸을 차지한다.
샘물은 최대 HP의 50%, 천사상은 최대 HP까지 회복한다.
인접한 위치에서 눌러 사용하며 한 층에서 1회만 사용할 수 있다.
사용은 한 행동이므로 몬스터 턴이 이어진다.

[전리품]
몬스터별 골드와 아이템 드랍은 DB를 따른다.
금화, 금괴, 등급별 상자 에셋이 낙하 모션과 함께 표시된다.
드랍 에셋은 지형·구조물·캐릭터보다 앞쪽인 전경 레이어에서 타일 바닥 위에 표시되어 가려지지 않는다.
전리품 바로 앞에서 눌러 습득한다.
아이템 상자는 잠금 해제, 뚜껑 개방, 내부 빛 분출의 4프레임 연출과 단계별 효과음을 재생한다.
등급에 따라 분출되는 빛의 색이 달라지며, 개봉 연출이 끝난 뒤 아이템과 골드를 지급한다.
인벤토리가 가득 차 남은 아이템이 있으면 열린 상자가 타일에 유지된다.

[심층 귀환 제한]
지하 11층부터는 생존 몬스터가 한 마리라도 남아 있으면 귀환석을 사용할 수 없다.
모든 몬스터를 처치한 뒤에는 정상적으로 귀환석을 사용할 수 있다.
귀환석 정보 팝업에 현재 심층 제한 규칙을 표시한다.
[보스방 진입]
- 보스가 배치된 층에 진입하면 공통 위협 팝업이 먼저 표시된다.
- 보스를 카메라로 보여준 뒤 귀환석 즉시 사용 또는 전투 확정을 선택한다.
- 전투를 확정하면 해당 층의 모든 보스를 처치할 때까지 귀환석을 사용할 수 없다.
- 선택과 귀환 봉쇄 상태는 진행 중 던전 DB 저장에 포함된다.
- 보스방에는 미믹이 아닌 전용 보상 상자가 반드시 1개 배치된다.
- 보스 처치 시에도 보스 위치에 유니크 이상 전용 상자가 확정으로 떨어진다.
- 보스 상자 등급: 15층 이하 유니크, 16~20층 전설, 21층 이상 신화.
- 전용 상자는 `ui/dungeon/loot/boss_reward_chest.png`를 사용한다.
[1~5층 스톤수프형 골격]
1~5층은 연결된 방, 좁은 통로, 다중 진입로와 병목으로 구성된 동일한 수작업 골격을 사용한다.
몬스터, 보물상자와 회복 시설은 방 내부에서 무작위로 배치하되 벽과 주요 문틈을 막지 않는다.
시작 지점에서 아래층 계단까지 항상 이동 가능한 경로를 유지한다.
주요 방 사이의 출입구 네 곳에만 닫힌 나무문 에셋을 배치한다. 일반 벽이나 막힌 통로에는 문을 만들지 않는다.
닫힌 문은 가로·세로 방향을 구분하며 이동·시야·투사체를 막는다.
문을 열면 플레이어가 접근한 방향의 반대쪽으로 경첩을 따라 회전하고, 열린 방향 에셋으로 바뀌어 이동과 공격이 통과한다.
인접한 문을 직접 누르면 1행동을 사용해 열며 몬스터 행동이 이어진다.
자동 이동 경로의 닫힌 문은 자동으로 열고, 전투 중이면 문 열기 행동을 처리한 뒤 목적지 이동을 계속한다.
문의 가로·세로 방향과 열린 방향은 원정 장애물 데이터에 함께 저장되어 앱을 종료한 뒤에도 유지된다.
[몬스터 시야 제한]
맵의 바닥과 지형은 항상 표시하지만 몬스터·이름·체력·경고 표시는 플레이어 시야 안에서만 표시한다.
기본 시야는 플레이어 주변 2칸이며 횃불이 활성화된 층에서는 5칸이다.
거리 안에 있어도 닫힌 문이나 벽으로 시야가 막히면 몬스터가 표시되지 않는다.
보이지 않는 몬스터는 터치하거나 공격 대상으로 선택할 수 없고, 몬스터 턴 카메라도 해당 위치를 노출하지 않는다.
[던전 바닥 표현]
1~5층 배경은 격자가 이미지에 중복되지 않는 전용 석재 바닥 에셋을 사용한다.
이동 타일은 배경을 가리지 않는 얇은 반투명 점선과 미세한 명암으로 표시한다.
화면 가장자리는 은은하게 어두워지고 중앙 전투 구역은 선명하게 유지된다.
1~25층은 5층 단위로 구분된 4x4 바닥 타일 아틀라스를 사용한다.
각 좌표의 타일 변형은 층과 좌표로 고정 계산되어 저장 후 재개해도 무늬가 바뀌지 않는다.
1~5층은 거미줄·발자국·점액·도적 흔적, 6~10층은 침수·이끼·뼈, 11~15층은 재·화로·쇠판 흔적을 사용한다.
16~20층은 악마성의 흑석·핏빛 균열, 21~25층은 심연의 흑요석·보랏빛 공허 문양을 사용한다.
