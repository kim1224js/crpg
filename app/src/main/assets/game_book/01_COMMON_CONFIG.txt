[점검 결과]
- 인벤토리와 창고 용량은 DB 값을 UI와 이동 제한에서 공통 사용한다.
- 창고 용량은 계정별로 저장하며 잊혀진 영주 처치 후 영구적으로 100칸까지 확장된다.
- 아이템, 몬스터, 드랍, 층 배치, 회복 시설 정의는 DB가 원본이다.
- 이미지와 음원 파일은 assets에 두고 DB에는 경로를 저장한다.
- base_vision, torch_vision, torch_duration_turns는 횃불이 층 공격력 +1로 변경되기 전 설정이다.
  현재 전투 효과에는 사용하지 않는 레거시 값이므로 추후 DB 정리 시 제거 후보이다.
- 맵 크기와 표시 타일 수는 아직 DungeonDemoView 코드 상수다. 맵 규격 변경 기능을 만들 때 DB 이전 후보이다.
