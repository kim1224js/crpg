1. 플레이어 기본 규칙
============================================================

- 기본 체력: 10
- 시작 골드: 10G
- 최초 지급 귀환석: 5개
- 던전 인벤토리: 5행 × 5열, 총 25칸
- 창고 기본 용량: 20칸
- 무게 시스템: 없음
- 기본 행동: 1턴에 이동, 공격, 아이템 사용, 장비 교체 중 하나
- 전투 배속: 1배 / 2배 / 3배
- 방어 성공 시: 피해를 받지 않고 MISS 표시
- 무기는 던전 입장 시 인벤토리에서 가장 왼쪽에 있는 무기를 기본 착용한다.
- 던전 전투 중 인벤토리의 무기를 눌러 교체할 수 있으며 1행동을 소모한다.
- 투구, 갑옷, 신발도 인벤토리에서 눌러 착용할 수 있으며 1행동을 소모한다.

2. 던전 구조와 진행
============================================================

[층 구성]
- 구현 범위: 지하 1층~지하 5층
- 입장 층: 항상 지하 1층
- 맵 크기: 24열 × 12행
- 한 화면 표시 범위: 8열 × 7행
- 맵은 드래그하여 전체 구역을 확인할 수 있다.
- 1~5층은 동일한 수작업 맵 골격을 사용하고 몬스터 위치는 방 내부에서 무작위로 정한다.
- 플레이어 시작 위치: (2, 8)
- 아래층 계단 위치: (22, 1)

[장애물]
- 현재 실제 배치 종류: 돌기둥, 죽은 나무
- 1~5층은 돌기둥 벽으로 구분된 방, 좁은 통로, 다중 진입로와 병목을 사용한다.
- 주요 문틈에는 몬스터·보물상자·회복 시설이 생성되지 않아 시작점부터 계단까지 경로가 유지된다.
- 고목과 독립 돌기둥은 방 내부의 전술 엄폐물로 고정 배치된다.
- 주요 방 사이 출입구에만 방향성 나무문이 배치된다. 직접 누르거나 자동 이동 경로에 포함되면 접근 반대편으로 열리고 방향 상태가 원정 저장에 보존된다.
- 맵과 지형은 항상 보이지만 몬스터는 기본 2칸, 횃불 활성 층에서는 5칸 이내이면서 시야가 연결된 경우에만 표시하고 선택할 수 있다.
- 1~5층은 격자 없는 석재 배경 위에 반투명 입체 타일을 별도로 렌더링하여 배경과 이동 범위를 함께 선명하게 표시한다.
- 1~25층 바닥은 5층 구간별 16종 타일 아틀라스를 사용하며 몬스터 생태와 구간 환경에 맞는 흔적을 고정 좌표 방식으로 배치한다.
- 장애물은 이동과 원거리 공격 시야를 막는다.

[계단]
- 해당 층의 몬스터를 모두 처치해야 계단이 열린다.
- 계단을 누르면 장애물을 피해 계단까지 자동 이동한다.
- 계단 자동 이동 중에는 턴과 몬스터 행동이 발생하지 않는다.
- 도착 후 탐험 완료 공통 팝업을 표시한다.
- 팝업에는 획득한 장비 목록만 표시되며 목록이 길면 본문 영역만 스크롤된다.
- 선택 버튼: 마을가기 / 내려가기
- 지하 5층에서는 내려갈 다음 층이 없으므로 마을가기만 표시한다.

3. 전투 규칙
============================================================

[플레이어 행동]
- 이동: 상하좌우 인접 1칸
- 공격: 착용 무기의 사거리와 특수 효과를 따른다.
- 장비 교체: 1행동 소모
- 소모품 사용: 1행동 소모. 귀환석은 즉시 안전 귀환 처리
- 전리품 습득: 전리품의 상하좌우 인접 칸에서 클릭, 1행동 소모

[공격 표시]
- 공격 가능한 타일: 노란색 계열
- 장애물에 막힌 공격 타일: 빨간색 계열
- 화염병 선택 가능 타일: 주황색 계열

[원거리 연출]
- 활과 총은 투사체가 표시된다.
- 카메라는 투사체 경로를 따라간 뒤 피격 몬스터에 포커싱한다.
- 총알 관통 시 다음 대상까지 카메라 추적이 이어진다.

[몬스터 행동]
- 플레이어 행동 후 살아 있는 몬스터가 한 마리씩 순서대로 행동한다.
- 각 몬스터 행동을 카메라가 개별 포커싱한다.
- 몬스터가 한 턴 이동하지 못하면 막힘 횟수를 기록한다.
- 다음 이동부터 BFS 우회 탐색으로 장애물과 다른 몬스터를 피해 움직인다.
- 무기의 공격 소모 턴이 2턴이면 몬스터 전체 행동 라운드도 2회 진행된다.

[화염]
- 화염 지대: 선택 지점을 중심으로 3×3
- 지속: 2턴
- 화염 지대 피해: 턴당 5
- 화상: 화염 피해를 받은 생존 몬스터에게 3턴 동안 턴당 3

4. 아이템 전체 정보
============================================================

모든 현재 상점 장비와 소모품의 등급은 NORMAL(최하위 등급)이다.
현재 등록된 각 아이템의 개별 몬스터 드랍 확률은 10%이다.


4-1. 일반 상점 소모품
----------------------

[횃불 / code: torch]
- 판매: 5개 묶음 1G
- 최대 중첩: 99
- 사용 조건: 플레이어 행동 차례
- 효과: 사용한 현재 층 동안 모든 무기 공격력 +1
- 중복 사용: 같은 층에서 불가
- 종료: 다음 층 진입 시 효과 해제
- 사용 행동: 1행동
- DB: 안전 귀환 시 사용 수량 차감

[귀환석 / code: return_stone]
- 판매: 1개 2G
- 최대 중첩: 99
- 효과: 생존 중 현재 던전에서 마을로 안전 귀환
- 결과: 획득 아이템과 획득 골드를 DB에 정산
- 소비: 1개
- DB: 귀환 처리 트랜잭션에서 즉시 1개 차감

[야영 세트 / code: camping_kit]
- 판매: 1개 3G
- 최대 중첩: 99
- 사용 조건: 플레이어 행동 차례, 현재 HP가 최대 HP보다 낮을 때
- 효과: HP를 최대치까지 완전 회복
- 최대 HP 상태: 사용되지 않고 수량도 줄지 않음
- 사용 행동: 1행동
- DB: 안전 귀환 시 사용 수량 차감

[화염병 / code: fire_bomb]
- 판매: 1개 2G
- 최대 중첩: 99
- 투척 사거리: 플레이어 기준 1~3칸
- 범위: 목표 타일 중심 3×3
- 화염 지대: 2턴 동안 턴당 피해 5
- 화상: 피격 후 3턴 동안 턴당 피해 3
- 사용 행동: 1행동
- DB: 안전 귀환 시 사용 수량 차감

[층 구간 고유 버프 소모품]
- 용병의 무기 기름 / 고급 / 1~5층 일반 몬스터 10% / 5개 드랍 / 현재 층 공격력 +1
- 사냥꾼의 눈물 / 레어 / 6~10층 일반 몬스터 8% / 5개 드랍 / 현재 층 사거리 +1
- 철벽의 성유 / 에픽 / 11~15층 일반 몬스터 6% / 5개 드랍 / 현재 층 일반 방어 +20%
- 악마의 피 / 유니크 / 16~20층 일반 몬스터 4% / 5개 드랍 / 현재 층 공격력 +2
- 심연 촉진제 / 전설 / 21~25층 일반 몬스터 3% / 5개 드랍 / 현재 층 공격력 +2, 사거리 +1
- 절대 수호의 성배 / 신화 / 10·15·20·25층 보스 20% / 1개 드랍 / 현재 층 다음 5회 공격 100% 방어
- 같은 소모품은 한 층에서 중복 사용할 수 없다. 다음 층 진입 시 효과가 종료된다.
- 활성 효과와 절대 수호 남은 횟수는 던전 하단 HUD 및 던전 진행 DB에 저장된다.

- 공격력: 3
- 소모: 1턴
- 사거리: 캐릭터 주변 1칸
- 범위 판정: 상하좌우와 대각선을 포함한 주변 8칸
- 특수 효과: 주변 8칸의 살아 있는 모든 몬스터를 한 번에 공격
- 횃불 적용 시 공격력: 4

[조잡한 창 / code: crude_spear]
- 가격: 5G
- 공격력: 4
- 소모: 2턴
- 사거리: 3
- 공격 방향: 상하좌우 일직선만 가능
- 특수 효과: 사거리 내 직선상의 모든 몬스터를 순서대로 찌름
- 장애물이 있으면 그 뒤로 공격할 수 없음
- 횃불 적용 시 공격력: 5

[조잡한 활 / code: crude_bow]
- 가격: 5G
- 공격력: 3
- 소모: 1턴
- 사거리: 4
- 특수 효과: 첫 공격 후 50% 확률로 같은 대상에게 한 발 추가 발사
- 장애물이 공격 경로를 막으면 공격 불가
- 횃불 적용 시 공격력: 화살 한 발당 4

[조잡한 총 / code: crude_gun]
- 가격: 5G
- 공격력: 5
- 소모: 2턴
- 사거리: 5
- 특수 효과: 일직선상의 앞 몬스터를 처치하면 뒤 몬스터에게 탄환 관통
- 앞 몬스터가 생존하면 관통 종료
- 장애물이 공격 경로를 막으면 공격 불가
- 횃불 적용 시 공격력: 6


4-3. 대장간 방어구
-------------------

[조잡한 갑옷 / code: crude_armor]
- 가격: 5G
- 착용 부위: 갑옷
- 효과: 인접한 적의 일반 공격을 30% 확률로 완전히 방어
- 방어 성공 시: MISS 표시, 피해 0
- 교체: 던전 인벤토리에서 터치, 1행동 소모

[조잡한 투구 / code: crude_helmet]
- 가격: 5G
- 착용 부위: 투구
- 효과: 2칸 이상 떨어진 적의 원거리 공격을 30% 확률로 완전히 방어
- 방어 성공 시: MISS 표시, 피해 0
- 교체: 던전 인벤토리에서 터치, 1행동 소모

[조잡한 신발 / code: crude_boots]
- 가격: 5G
- 착용 부위: 신발
- DB 설명: 이동 시 50% 확률로 이동 거리 +1
- 교체: 던전 인벤토리에서 터치, 1행동 소모
- [구현 주의] 현재 이동 거리 +1 확률 효과는 전투 이동 코드에 아직 적용되지 않았다.

[방어 확률 판정]
- 갑옷의 일반 방어와 투구의 원거리 방어는 공격 거리별로 따로 판정한다.
- 철벽의 성유 사용 중에는 갑옷 일반 방어와 합산되며 최종 확률은 100%를 넘지 않는다.
- 유니크 이상 투구·갑옷·신발을 하나 이상 착용하면 피해 10 이상의 공격을 50% 경감한다.
- 유니크 이상 방어구를 여러 부위 착용해도 경감률은 중첩되지 않으며 홀수 피해는 올림 처리한다.

5. 드랍과 전리품
============================================================

[골드 드랍]
- 모든 몬스터의 골드 드랍 확률: 70%
- 거미: 1G
- 들개: 1G
- 도적: 2G
- 슬라임: 1G

[보스방 경고와 귀환 봉쇄]
- 보스층 진입 시 위협 팝업을 표시하고 보스를 포커싱한 뒤 즉시 귀환 여부를 묻는다.
- 전투를 선택하면 모든 보스를 쓰러뜨릴 때까지 귀환석 사용이 봉쇄된다.
- 보스방에는 유니크 이상 전용 상자가 항상 배치되며 미믹으로 변하지 않는다.
- 각 보스는 처치 위치에 유니크 이상 보스 전리품 상자를 확정으로 추가 드랍한다.
- 보스에게는 일반 몬스터용 조잡한 장비 공통 드랍을 적용하지 않는다.
- 보스 상자 보상은 정산 시 낮은 등급의 일반 전리품보다 먼저 저장한다. 인벤토리가 찼다면 이번 탐험에서 얻은 가장 낮은 등급 장비 하나를 대신 제외해 보스 장비를 보존한다.
- 15층 이하 유니크, 16~20층 전설, 21층 이상 신화 상자를 사용한다.

[아이템 드랍]
- 현재 등록된 각 아이템이 몬스터 사망 시 각각 독립적으로 10% 확률 판정
- 여러 아이템이 한 몬스터에게 동시에 드랍될 수 있음
- 돈과 아이템은 몬스터가 죽은 칸에 생성
- 1G는 금화 에셋, 10G 이상은 금괴 에셋 사용
- 장비와 아이템은 등급별 상자 에셋 사용
- 드랍 직후 약 0.9초 동안 공중으로 튀어 올랐다가 착지
- 착지 전에는 습득 불가
- 전리품의 상하좌우 인접 칸에서 클릭하여 습득
- 인벤토리가 가득 차면 골드는 습득되지만 들어갈 칸이 없는 아이템은 바닥에 남음

[상자 등급 색상]
- NORMAL: 기본
- HIGH: 녹색
- RARE: 파란색
- EPIC: 보라색
- UNIQUE: 주황색
- LEGENDARY: 붉은색
- MYTHIC: 밝은 황금색

7. 사망과 안전 귀환
============================================================

[안전 귀환]
- 귀환석 사용 또는 층 완료 후 마을가기로 실행
- 획득 골드와 획득 아이템 보존
- 던전에서 사용한 기존 소모품 수량을 Room DB에서 차감
- 던전에서 주운 소모품을 사용했다면 획득분에서 먼저 차감
- 안전 귀환 시 생존 일수 +1

[사망]
- 플레이어 HP가 0이 되면 사망 모션 후 게임 오버
- 현재 캐릭터의 INVENTORY 컨테이너 아이템 전체 삭제
- STORAGE 컨테이너의 창고 아이템은 유지
- 마을에 보관된 골드는 유지
- 사망 캐릭터 이름, 도달 층, 생존 턴, 사망 시각을 DB에 기록
- 로그인 화면으로 이동하여 새 캐릭터 이름 입력
- 저택에서 사망자 목록 확인 가능

8. DB 정산 규칙
============================================================

- 아이템 정의: item_definition
- 몬스터 정의: monster_definition
- 보유 아이템: owned_item
- 로그인/골드/생존일: login_profile
- 닉네임 계정: nickname_account
- 사망자: deceased_character
- 감정 규칙: appraisal_rule
- 공통 수치: game_config

[던전 소모품 정산]
1. 던전 입장 당시 가진 수량과 던전 획득 수량을 로컬에서 함께 표시한다.
2. 소모품 사용 시 획득분이 있으면 획득분부터 감소시킨다.
3. 획득분이 없으면 consumedCounts에 기존 보유분 사용량을 기록한다.
4. 안전 귀환 트랜잭션에서 기존 보유분 사용량을 owned_item에서 차감한다.
5. 남은 획득 아이템을 owned_item에 추가한다.
6. 귀환석 귀환이면 귀환석 1개를 별도로 차감한다.
7. 사망 시에는 안전 정산을 하지 않고 INVENTORY 전체를 삭제한다.


============================================================
9. 구현 주의 및 미완성 항목
============================================================

1) 조잡한 신발
- DB에는 이동 시 50% 확률로 +1칸 효과가 기록되어 있다.
- 현재 던전 플레이어 이동은 상하좌우 1칸으로 고정되어 있어 실제 효과는 미적용이다.

2) 장비 내구도
- owned_item에 dungeonUseCount와 durability(기본 3) 컬럼은 존재한다.
- 장비를 던전에 3회 가져가면 파괴되는 처리와 파괴 후 50% 제작 처리는 아직 실제 흐름에 연결되지 않았다.

3) 소음/예민지수
- 현재 monster_definition에는 예민지수 컬럼이 없다.
- 몬스터는 현재 플레이어 위치와 공격 가능 거리 기준으로 행동한다.

4) 횃불 과거 설정값
- game_config에 torch_vision=5, torch_duration_turns=10 값이 남아 있다.
- 현재 실제 횃불 동작은 시야 확장이 아니라 해당 층 공격력 +1이며 위 두 값은 사용하지 않는다.

5) 방어구 중첩
- 갑옷과 투구가 각각 BLOCK_CHANCE_30으로 등록되어 있으나 최종 판정은 하나 이상 착용 시 30%로 고정된다.

6) 층별 난이도
- 현재 1~5층은 몬스터 수치, 위치, 장애물 배치가 동일하다.
- 층 증가에 따른 능력치 강화나 추가 몬스터는 아직 없다.

14. 던전 배경음악과 회복 오브젝트 (DB v19)
============================================================

[구간별 배경음악]
- 1~5층: 바람과 물방울이 들리는 어두운 폐허 던전 앰비언스
- 6~10층: 침수 카타콤의 음산한 성가
- 11~15층: 재의 용광로 구간에 맞춘 위협적인 저음 테마
- 층 구간이 바뀌면 음악이 자동 전환된다. 설정의 배경음악 ON/OFF를 공통 적용한다.

[회복 오브젝트]
- 각 층 진입 시 30% 확률로 회복 시설 하나가 무작위 위치에 등장한다.
- 등장 시설은 회복의 샘물 또는 천사의 성상 중 무작위로 선택된다.
- 회복의 샘물: 최대 HP의 50%를 회복한다.
- 천사의 성상: HP를 최대치까지 회복한다.
- 두 시설 모두 2×2, 총 4칸을 점유한다.
- 시설 바로 옆에서 네 칸 중 하나를 터치해야 하며, 해당 층에서 1회만 사용할 수 있다.
- 체력이 가득 찬 상태에서는 소모되지 않는다. 사용은 1행동으로 처리되어 몬스터 턴이 진행된다.
- 정의, 회복 비율, 에셋 경로, 점유 크기와 등장 확률은 DB에서 관리한다.

[미감정 장비 사용]
- 고급 이상 드랍 장비도 획득 후 실제 이름, 아이콘과 기본 옵션을 확인하고 즉시 장착할 수 있다.
- 유니크·전설·신화 장비를 습득하면 전체 기본 옵션과 수명을 공통 팝업으로 즉시 보여준다. 여러 개를 동시에 습득하면 한 개씩 차례로 확인한다.
- 던전 보물상자 또는 마을 뽑기상자에서 장비가 나오면 등급과 관계없이 플로팅 결과 연출 후 전체 장비 정보 팝업을 표시한다.
- 미감정 상태에서는 DB 기본 성능과 기본 수명을 사용한다.
- 감정은 사용 가능 여부를 해제하는 절차가 아니라, 성공 시 개별 능력치와 수명을 변동해 DB에 저장하는 절차다.

[던전 인벤토리 정리와 버리기]
- 아이템 정보창에서 이동을 누른 뒤 다른 슬롯을 선택하면 빈칸으로 옮기거나 두 슬롯을 서로 교환한다.
- 슬롯 배치는 진행 중 던전 저장 데이터에 포함되어 앱을 다시 실행해도 복원된다.
- 장착하지 않은 아이템은 한 개씩 버릴 수 있으며 캐릭터 발밑에 전리품으로 생성된다.
- 아이템 버리기는 1행동을 소비하고, 떨어뜨린 아이템은 현재 칸 또는 인접·대각선 칸에서 다시 습득할 수 있다.

[전투 중 회복 표시]
- 전투 중 회복은 장착 장비·유물·소모품·회복 시설의 정해진 효과로만 발생한다.
- 무기의 처치 회복이 발동하면 무기 이름과 HP 1 회복을 전투 메시지에 표시한다.

15. 던전 원정 저장 (DB v21)
============================================================

- 원정 상태는 닉네임 계정 ID별 dungeon_run 테이블에 JSON 스냅샷으로 저장한다.
- 플레이어 행동과 이어지는 몬스터 행동이 모두 끝나 안정 상태가 될 때마다 자동 저장한다.
- 층, 턴, HP, 위치, 소지품, 획득품, 소비품, 장착 장비, 몬스터 상태와 위치, 장애물,
  미습득 전리품, 화염 지대, 회복 시설과 사용 여부, 주요 유물·상태이상 진행값을 보존한다.
- 앱을 종료한 뒤 같은 닉네임으로 다시 입장하면 마지막 완료 행동 직후 상태에서 자동 재개한다.
- 로그인 후 마을에 진입했을 때 저장된 원정이 있으면 층·턴·HP를 표시하는 공통 팝업을 연다.
- '탐사 이어가기'를 누르면 즉시 저장 지점으로 복귀한다. '마을에 머물기'를 선택해도 기록은 유지되며 지하 입구에서 다시 이어갈 수 있다.
- 귀환·정상 탐사 종료·사망 시 해당 원정 스냅샷을 삭제한다.
- 사망 화면은 HP를 0으로 만든 마지막 피해를 기준으로 일반 공격·중독·화상·유물 반동을 구분하며, 원인이 된 몬스터 또는 유물 이름을 함께 표시한다.
- HP가 0이 되는 순간 사망 복구 기록을 먼저 영구 저장한다. 세대 교체 DB 처리 도중 앱이 종료되어도 다음 실행에서 중복 없이 처리를 완료한다.
- 이미지와 음원 바이너리는 APK assets에 저장하며 DB에는 경로와 게임 설정을 저장한다.
